# 노슈니 사이트

블로그를 글만 쓰면 페이지가 생기는 구조로 만든 것입니다.

## 새 글 쓰는 법

`content/blog/` 폴더에 파일을 하나 만들면 끝입니다. 파일 이름이 곧 주소가 됩니다.
`content/blog/7.md` 를 만들면 `/blog/7` 이 생깁니다.

파일 맨 위에 이렇게 적고, 그 아래에 본문을 씁니다.

```
---
title: "글 제목"
description: "검색 결과에 보일 한두 문장"
category: "AI 실무"
published: 2026-09-20
readingTime: 8
---

여기부터 본문입니다. 마크다운으로 쓰면 됩니다.

## 소제목

문단은 그냥 쓰면 되고, **굵게** 나 [링크](https://example.com) 도 됩니다.
```

깃허브에 올리면 1~2분 안에 사이트에 반영됩니다. 목록 페이지와 사이트맵에도 자동으로 들어갑니다.

아직 공개하고 싶지 않으면 `draft: true` 를 한 줄 추가하세요. 사이트에 안 나옵니다.

HTML 로 쓰고 싶으면 `.md` 대신 `.html` 로 만들면 됩니다. 기존 글 6개가 그 방식입니다.

## 폴더 설명

| 폴더 | 무엇 |
|---|---|
| `content/blog/` | 글. 여기만 건드리면 됩니다 |
| `app/globals.css` | 디자인. 색과 글꼴이 전부 여기 |
| `components/` | 모든 페이지가 같이 쓰는 머리말·꼬리말 |
| `app/blog/` | 목록 페이지와 글 페이지의 틀 |
| `lib/posts.js` | 글 파일을 읽어오는 코드 |

메뉴를 바꾸려면 `components/Header.jsx` 의 `MENU` 부분만 고치면 모든 페이지가 한 번에 바뀝니다.

## 로컬에서 보기

```bash

npm run dev
```
